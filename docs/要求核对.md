## 需要注意的原文不一致

文档 0.2 写“两个部署链接”，第五节又推荐三个实验分开部署并“提交三个独立地址”。本项目按后文要求分别部署 CSR、SSR 和 SSG，三个公开地址已列在根目录报告和 [运行与提交](运行与提交.md) 中。

文档使用“零计算”“首屏响应最快”等教学简化表述。本报告保留实验目的，同时说明实际静态服务仍有成本，速度应由具体环境测量决定。水合问题也区分框架组件交互与 HTML 原生能力。

## 实现与任务示例

任务书通过占位文章、Express 路由和 SSG 写文件示例说明渲染原理。本项目保留对应技术路线，将内容设为十篇学习札记，并让三个入口共用数据和模板，便于比较生成时机。

受控数据更新、禁用 JavaScript 和重复请求实验提供相互补充的证据。时间戳验证按课程提示使用，性能分析则以本机实际采集的数据为依据。
